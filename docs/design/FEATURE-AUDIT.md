# 当前界面的功能核对

## 基线与口径

原版基线为 [Sub-Store Front-End 2.34.4](https://github.com/sub-store-org/Sub-Store-Front-End/tree/4d94748b80c2bb946569636a9abc22016f8dcb05)，视觉仍使用已确认稿。没有重新引入原版布局，也没有另造后端或数据模型。

静态检查遍历原版 57 个 Vue 组件，逐组件对照去除注释后的模板双向绑定；组件内去重后共 265 项。唯一从原模板移出的绑定是同步开关，当前通过管理弹层的读取／写入控制继续调用原保存流程。此口径不等于 265 个独立设置，也不等于所有业务分支已实际执行。

运行时使用相同隔离示例数据打开原版：确认流量总额、同步来源、日志刷新与多选、语言切换原本可用。新版回归测试验证了修复前的缺失或遮挡，再验证修复后行为。来源版本、平台限制、接口与保存逻辑继续沿用原实现。

## 已补齐

| 功能 | 原因 | 当前实现与验证 |
|---|---|---|
| 订阅已用／总流量、到期与组合来源 | 卡片只取第二行或备注；简洁模式直接隐藏详情 | 使用原流量与来源计算结果，备注按外观偏好处理；普通／简洁模式均检查数值、日期和来源 |
| 分享次数与到期信息 | 详情错误地与“显示备注”共用条件 | 关键有效性信息始终显示，备注仍可隐藏；检查次数及剩余用途 |
| 同步来源、最近执行与开关状态 | 备注替代业务详情，开关状态只在管理中可见 | 合并原来源、时间和自动同步状态；开关仍在管理中调用原 API |
| 归档上下文与备注 | 卡片仅显示归档时间，简洁模式还会隐藏 | 保留来源上下文、格式化时间和允许显示的备注；两种模式均覆盖 |
| 标签可读性 | 原标题标签从新卡片中移除，管理中未补 | 管理弹层逐资源显示原标签；筛选仍与搜索叠加 |
| 语言切换 | 隐藏触发器的父容器同时隐藏了弹层 | 仅隐藏重复触发按钮，独立保留语言弹层；实际切换到 English 并核对页面更新 |
| 日志刷新、清空与多选 | 按钮传送到页面顶层后位于详情遮罩之下 | 操作栏放回日志面板，沿用原动作；通过真实点击命中检查与多选验证 |
| 已折叠列表的恢复 | 分组标题隐藏后，旧折叠状态缺少可见说明 | 只在有折叠分组时显示状态与“展开全部分组”；调用原展开流程，保留折叠能力 |
| 同步平台和空列表限制 | 新管理入口没有接回原按钮条件 | GitLab 不显示下载入口；空列表不显示上传入口；保留运行中的禁用状态 |

对应回归位于 `web/tests/capabilities.spec.ts`；长内容、手机／桌面、深浅主题截图与横向溢出检查位于 `web/tests/capability-layout.spec.ts`。现有几何、交互、设置保存、编辑器、无障碍、原生缓存与真实后端测试继续执行。

## 其余模块的核对范围

| 模块 | 核对结果与证据 |
|---|---|
| 设置与后端管理 | 十类入口及原表单绑定仍在；设置保存、主题、图标、导航偏好有交互回归，后端管理与高级设置有详情渲染回归 |
| 远程／本地／组合编辑 | 原来源、请求与输出、展示、加工链条件与绑定保留；远程链接保存、手机新建、字段分组有交互回归 |
| 文件与代码编辑 | 原来源、类型、内容、加工链与代码工具保留；分类、副本、导出及真实后端归档恢复有回归 |
| 分享与归档管理 | 原筛选、排序、选择、到期模型、批量删除／恢复逻辑保留；批量选择及“归档／彻底删除”选择实际打开验证 |
| 日志与预览 | 原检索、正则、大小写、条数、定时刷新、结构化内容、复制与预览实现保留；本次修复入口遮挡，不改日志协议 |
| 离线与登录 | 原生工作线程回归继续覆盖登录回调、已有标签页升级与离线页面导航 |

## 已确认的视觉差异

重复页头、常驻说明行、图标说明入口和列表工具栏刷新按钮按确认稿移除。常驻搜索、默认完整配置、文件纯图标操作常显、设置命名继续保留。原滑动菜单的功能已进入卡片或管理弹层；不为恢复功能而恢复旧视觉。

## 验证边界

自动化使用隔离数据，不写生产订阅或外部账户。Gist／GitLab 上传下载、真实外部订阅、实体 iOS／Safari 和辅助读屏设备未在本轮逐项执行；这些集成保留原实现，不能据源码保留宣称服务端执行成功。数据保存的 API 验收与界面可达性验收分别报告。
