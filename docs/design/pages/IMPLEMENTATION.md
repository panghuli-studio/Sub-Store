# 界面实现

## 设计基线

确认稿、截图和历次评论保存在提交 `cac2e970`，文件位于 `docs/design/mockups/`。`docs/design/approved-baseline.json` 固定文件摘要；实现期间不修改确认稿来适配新代码。

正式前端位于 `web/`，基于 Sub-Store-Front-End 2.34.4 的提交 `4d94748b80c2bb946569636a9abc22016f8dcb05`。确认稿的模拟数据层不参与产品构建。

## 界面约定

- 六个主页面采用确认稿的导航、常驻搜索和卡片。没有页面眉题、标题、副标题、重复搜索图标和列表刷新按钮。
- 默认列表不展示额外筛选行、卡片顶部复选框或“未标记”占位。筛选、导入、分组折叠、来源、输出选项及批量操作进入管理弹层。
- 订阅卡片仅保留一排更新、分享、复制、编辑。文件七个操作直接展示，没有展开或收起按钮。
- 文件默认选中完整配置；完整配置、节点文件和普通文件互斥，普通文件仍可访问。类别可以在文件编辑器中指定，不依赖自动识别结果。
- 设置分为十类。原字段、校验、密钥辅助、备份格式和后端能力条件仍由原实现处理。
- 标准深浅主题使用确认稿的变量；原版自定义主题、图标填充、简洁模式和宽屏窄导航仍可设置。
- 图标操作有工具提示和可访问名称。新按钮使用 Reka UI；原 NutUI 按钮保留原事件，并补键盘操作。

## 功能入口

| 能力 | 当前入口与实现 |
|---|---|
| 订阅、组合、新建和链接修改 | 订阅工具栏、原 SubEditor、原订阅 API |
| 导入、标签和来源筛选、流量、客户端输出、副本、导出和删除 | 订阅管理弹层；调用原页面或卡片处理函数 |
| 文件分类、内容、下载、引用、加密、失败策略和加工链 | 文件分类标签、原 FileEditor 和七个卡片操作 |
| 节点处理、脚本、参数、排序和逐项预览 | 原 ActionBlock、CommonBlock、处理器及代码编辑器 |
| 节点前后对比和文件结果预览 | 原 CompareTable、FilePreview、PreviewPanel |
| 同步输出、定时表达式、单项和批量上传下载 | 原 SyncEditor、卡片和管理弹层；自动同步开关及全局定时信息在管理弹层 |
| 分享的到期模式、次数、时间、Token、age、二维码和地址 | 原分享编辑器、分享卡片和管理弹层 |
| 五类归档、标签、排序、多选、恢复和删除 | 原归档页面、卡片和管理弹层 |
| GitHub、请求、缓存和前端配置 | 设置对应分类；复用原输入绑定与保存 API |
| Gist 与手动备份恢复、下载令牌策略 | 设置的备份与恢复分类；复用原序列化和同步函数 |
| 外观、更多选项和数据清理 | 设置的外观与交互分类 |
| 多后端、相对地址、分享基础地址和连接检查 | 设置的后端管理分类，原 APISetting |
| 日志过滤、自动刷新、复制和清空 | 设置的 Sub-Store 日志分类，原 LogsPanel |
| 语言和版本信息 | 设置的语言、关于分类 |

表中“原实现”表示保留上游业务函数和数据协议，不表示所有外部服务都已实测。独立后端的验证范围见验收记录；外部账户同步没有使用测试凭据冒充成功。

## 组件与构建

Vue 3、NutUI 3.3.8、Pinia、Vue Router、CodeMirror 和原 API/store 保持原技术栈。新增 Reka UI 2.11.0 与 Floating Vue 5.4.0 分别提供原生语义控件和工具提示；Playwright 1.65.1、axe-core/playwright 4.14.1 仅用于验证。NutUI 3 的按钮实际输出 `view`，键盘适配的原因记录在 `docs/design/COMPONENTS.md`。

镜像构建通过 `.github/panghuli/build-frontend.sh` 编译 `web/`。CI 与发布使用同一份源码，不再下载另一份未经修改的前端。合并部署默认连接当前服务地址；显式 API、保存的后端及 URL 参数仍优先。

## 验证

在 `web/` 执行：

```sh
pnpm lint
pnpm typecheck
pnpm design:check
pnpm test
pnpm build
pnpm exec playwright test --workers=2
```

真实后端检查使用独立数据目录和回环地址，不修改系统代理、路由或服务。先在 `backend/` 构建，再在 `web/` 执行：

```sh
UI_BACKEND_DATA="$(mktemp -d)" UI_BACKEND_PORT=4323 sh tests/check-live.sh
```

脚本拒绝复用已占用端口；结束时关闭自己启动的后端。CI 执行相同流程。需要后台预览时，使用 `tests/run-backend.sh` 并显式传入独立数据目录。
