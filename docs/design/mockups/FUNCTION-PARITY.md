# 原版功能保留

界面调整不得删除原有设置、字段、入口、条件分支、校验或编辑流程。移动入口时必须保持可达；已有功能是否可用继续由原版的后端版本、能力开关及配置条件决定。

## 基线与实现

基线：Sub-Store Front-End 2.34.4，提交 `4d94748b80c2bb946569636a9abc22016f8dcb05`。

默认界面由 `site/App.vue` 与当前设计组件组成，不加载原版页面或 iframe。原版源码仅用于核对字段和操作，不能以文件存在或源码一致代替当前设计的功能验收。

当前设计组件：`SettingsView.vue`（设置）、`ResourceEditor.vue`（订阅／文件／同步／分享）、`ProcessorEditor.vue`（加工链）、`CodeEditor.vue`（代码工具）、`ResourcePreview.vue`（文件与节点比较）、`LogsPanel.vue`（日志）。FormKit 2.10.0 管理表单，CodeMirror 6 管理代码编辑，qrcode 1.5.4 生成示例链接二维码，保留原有 Vue 与图标体系。

## 已确认的界面调整

导航改为“设置”；取消重复页头、说明入口和列表刷新按钮；搜索常驻；文件默认完整配置；文件操作直接展示、图标保留名称和提示。增加“普通文件”分类保留原版普通文件管理，避免将导入清单等隐藏到无入口状态。

## 当前设计中的行为

- 新增、编辑、字段保存、标签筛选、分类、拖拽排序、批量选择、导入导出、删除和归档恢复操作本地示例数据。
- 设置含 10 类卡片和条件字段；多后端支持地址解析、重复地址处理、增改删与切换，手动备份支持真实的示例 JSON 文件往返。
- 14 种加工类型保留原版参数与启停、排序、复制、导入、预览入口。脚本和远程操作不在设计稿执行。
- 分享有来源、Token、时长／日期／次数、二维码；同步有来源、客户端、上传开关、单项／全局定时和批量操作入口。
- 文件默认完整配置，节点文件与普通文件独立可达；文件七个操作全部以带提示的图标常显。

文件存在及一致性只能证明源码保留，不能等同于每条业务流程已验收。浏览器走查另列于 `REVIEW.md`。

此处是示例数据预览。设置和示例数据在浏览器本地保存；不连接生产，不校验真实外部后端，不执行远程订阅下载、节点转换、Gist 上传或定时任务。需要真实服务的操作会提示预览边界。正式实现仍须进行真实测试环境 API 验收，不可据此宣称后端执行成功。
