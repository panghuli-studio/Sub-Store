# 交互范围

| 页面 | 可操作内容 |
|---|---|
| 订阅 | 来源与组合订阅卡片；刷新、搜索、新建、分享、复制、编辑 |
| 文件 | 完整配置与节点分类；分享、复制后台下载链接、编辑、更多；展开后预览、创建副本、导出文件配置、删除 |
| 同步 | 立即同步、复制、编辑任务、删除；编辑中选择目标与启用计划 |
| 分享 | 编辑来源、复制分享链接、编辑设置、删除 |
| 归档 | 恢复、永久删除确认 |
| 我的 | 后端连接、主题、备份与恢复 |
| 图标说明 | 按页面列出易混操作及区别 |
| 交互说明 | 范围、已审查事实、设计提案和验收要点 |

提示使用同源字典生成短文案和 `aria-label`；视觉图形设为装饰。悬停延迟 300ms，键盘聚焦显示，Esc 关闭。提示可以被鼠标移入，不因卡片裁切。文件更多菜单使用有提示的纯图标按钮。图标说明不再提供页面入口。

编辑、预览（原始/处理结果）、分享、同步、后端连接、外观、备份、删除确认、日志均为模态层。原生弹层限制焦点，Escape 关闭并返回触发位置。日志支持演示刷新、清空、复制；保存有短暂等待与结果提示。必填字段由浏览器校验。

列表演示正常、加载、空、出错、未连接、只读；搜索无结果单独显示；复制/保存/导出/删除/恢复/同步有文字反馈。只读时变更按钮保留可聚焦的限制提示。

未覆盖：真实后端的异常类型、权限模型、真实令牌生成与过期、文件执行过程、真实剪贴板/下载、离线持久化、完整多步订阅加工编辑流程。以上不是原型可宣称实现的能力。

所有列表页显示常驻搜索框，按名称即时筛选；文件分类与搜索可叠加，默认选中完整配置，清空搜索恢复当前分类下的列表。不再使用搜索展开按钮或「全部」标签。
